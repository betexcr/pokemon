## Known deltas (implementation vs cart)

- **RNG + replay artifacts:** Battle RNG is stored under RTDB **`server/battleRng`** (`seed`, `state`, `calls`), initialized in [`create-rtdb-battle.ts`](../src/lib/server/create-rtdb-battle.ts) / Admin battle create. [`resolveTurn`](../src/lib/battle-resolution.ts) reads `server/battleRng` first and falls back to legacy **`meta.battleRng`** during migration, then writes the advanced seed back to `server/battleRng` (and clears `meta.battleRng`). Each resolved turn writes replay metadata (`p1Action`, `p2Action`, `rngBefore`, `rngAfter`, `stateHashAfter`) to `turns/{turn}/resolution`.
- **Server validation/normalization:** `resolveTurn` uses [`normalizeServerBattleAction`](../src/lib/team-battle-engine.ts) with `meta.ruleProfile` (`simplified` default) to coerce safe edge cases (e.g. Struggle) and reject unsafe ones with explicit reason codes persisted to `public.lastValidation`.
- **Move data:** Moves load from PokeAPI via [`getMove`](../src/lib/moveCache.ts); failures log `engine_warning` and skip the move. A built-in fallback exists for **Struggle** if the network fails. Priority abilities prefer **cached** move metadata (`getCachedMove`) when available.
- **Hydration:** [`hydrateTeam`](../src/lib/battle-resolution.ts) uses embedded `pokemon.stats` on private team snapshots when present; otherwise it fetches PokeAPI with an in-process dedupe cache per species key. If fetch fails or returns no stats, hydration **throws** (`Missing base stats…`) and resolution treats the turn as a recoverable error — it does **not** silently substitute placeholder base-50 stats. HP still uses `maxHp` / `currentHp` from the snapshot when set. Submitted teams should include stats (Admin create deep-clones payloads so client-provided stats are preserved in RTDB).
- **Client reconstruction:** [`FirebaseRTDBBattleEngine`](../src/lib/battle-engine-rtdb.ts) builds the opponent team from **public** RTDB only (active + bench); full opponent sets are not read from the other player’s private node.
- **Sleep wake (intentional blend):** Cart Gen 9 uses a sleep counter decremented at end of turn only. The engine adds a **30% early-wake roll at start of turn** for livelier battles, plus end-of-turn counter decrement. Both paths log `"[Name] woke up!"`.
- **Freeze thaw timing:** Spec text places thaw at end of turn; the engine rolls **20% at start of turn** in `applyStartOfTurnStatus` (same message: `"[Name] thawed out!"`).
- **Status cure battle log:** Team cures via **Heal Bell** / **Aromatherapy**; ability/item cures (Lum Berry, Shed Skin, Hydration) also write to `battleLog` for display in offline and RTDB battles via `battleLogToDisplayLines`.
- **Stat-change targeting:** status moves use PokeAPI `target` (cached as `CompiledMove.target`) so Swagger-style moves affect the foe; damaging moves (and moves cached before `target` existed) fall back to boosts → user, drops → foe. Stat changes from PokeAPI data are applied once (previously status moves applied them twice).
- **Pivot UX:** U-turn / Volt Switch / Flip Turn / Parting Shot / Baton Pass let the **player pick** the replacement when two or more bench Pokémon can come in: the turn pauses (`state.pendingSwitch`, `runBattleTurnFromQueue` returns `'awaiting-switch'`) and `resumeBattleTurnAfterSwitch` finishes it. Offline, only the player picks (the AI sends in its next healthy Pokémon); in multiplayer both players pick (protocol in [`battle-pending-switch.ts`](../src/lib/battle-pending-switch.ts)). With a single option, or when the pivot KOs the foe's last Pokémon, there is no prompt. **Faint replacements** at end of turn work the same way: a player-controlled side with two or more healthy options picks (`runBattleTurnFromQueue` returns `'awaiting-replacement'`, apply with `applyFaintReplacements`). Both sides pick at the same time when both actives fainted, and the player picks again if entry hazards knock out the newcomer. In multiplayer this is `meta.pendingReplacement = { uids }` on the next turn number. Only listed players may submit, and only a legal switch (otherwise `illegal_replacement`). The AI and single-option cases stay automatic.
- **Held items:** players pick a held item per team slot in the team builder from the engine-supported list in [`battle-items-catalog.ts`](../src/lib/battle-items-catalog.ts) (`TeamSlot.item`). Offline setup and `normalizeTeamForRTDB` only accept items from that list (`heldItem` on the battle Pokémon). Before this, no app battle had held items.
- **Default abilities:** team slots rarely name an ability, so battle Pokémon start with an explicit slot `ability` if present, else the species' first non-hidden ability ([`resolveBattleAbility`](../src/lib/battle-default-ability.ts)), offline and in multiplayer. Before this, no ability effects ran in app battles.

- **Stats:** every stat uses the main-series formula with 31 IVs, the slot's **EVs** (team builder; 252 per stat, 510 total, sanitized everywhere a team enters a battle) and **nature** (previously only Speed used the nature and nothing used EVs). See [`battle-evs.ts`](../src/lib/battle-evs.ts) / [`battle-stats.ts`](../src/lib/battle-stats.ts).
- **Gender:** optional per slot in the team builder; Attract, Cute Charm and Rivalry act only on known genders.
- **Offline AI** ([`offline-battle-ai.ts`](../src/lib/offline-battle-ai.ts)): scores moves with real move data (it used to see only move ids, so every attack looked the same) and an estimate of the damage formula (stat stages, abilities, items, weather, screens, variable power, immunities); skips moves that would fail; values Protect, setup, hazards, screens, healing and status by the situation; switches on clearly losing matchups (turns-to-KO), never while trapped; picks faint / pivot replacements by matchup (`state.autoSwitchPicker`, offline only); uses the battle RNG, so offline battles are reproducible. Fixed: offline battles dropped the team builder's held items and Tera Types.

- **Gym leaders / Elite Four / Champions:** [`champion-sets.ts`](../src/data/champion-sets.ts) gives every slot at level 30+ a moveset, ability, nature and EVs (half EVs and an item only on the ace below level 50; full sets with items and Tera Types from 50). Generated by [`scripts/generate-champion-sets.mjs`](../scripts/generate-champion-sets.mjs) from Pokémon Showdown's curated random-battle sets; static, so battles never depend on it at runtime. Leaders below level 30 keep level-up moves and no items, as in the games. Unevolved Pokémon without a curated set of their own borrow their evolution's set, keeping only moves they can learn (Showdown learnsets) and topping up from their own learnset; situational moves (Steel Roller, Dream Eater, charge and recharge moves, ...) are never auto-picked and at most one self-KO move is kept.
- **Team builder abilities:** a slot may choose any of its species' abilities, hidden ones included. Offline battles and `normalizeTeamForRTDB` only accept abilities the species can have (else the first regular ability). The builder shows the six battle stats for the level, nature and EVs, and locks gender for single-gender and genderless species (PokeAPI `gender_rate`).
